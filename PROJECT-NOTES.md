# Design by Cristina website, in plain English

**What this is.** designbycristina.com as simple files. Every page is a file you can open. There is no dashboard (no Decap) and no build step.

**How it goes live.** Push `main` to GitHub. Netlify publishes it.

**How to change things.** Tell Claude what to change and Claude edits the files and commits. Small text fixes can also be made directly on GitHub.

**Articles.** Write and edit each article as a Google Doc in the "DBC Article Writer [Do Not Delete]" folder in the DBC Drive (Drafts, then Published). The images go in the Images folder next to it. When an article is final, Claude turns the Doc into the page, adds it to Resources and the sitemap, and updates the tracker.

**Products.** Product pages and checkout live in Teachery, so a new product never needs a change here. The Shop page shows a few top picks and links to the full Teachery store.

**Pushing.** When you say "push," Claude pushes. Each push costs Netlify build credits, so changes are saved together and pushed once. Claude commits changes locally first.

**Clarafide and the demo.** The Clarafide page here is a short overview with one button to the demo. The demo (demo.designbycristina.com) is its own project and uses the same colors. Later it becomes yourclarafide.com, with each spa's clients at yourclarafide.com/spa-name. Users are spas who log in; clients are spa customers who never log in.

**Writing rules.** Website is one word. Never use em dashes. No bold. The only italics are the article author line and the skincare link.

**Retired.** The old articles project (dbc-resources) is retired. Articles live here now.
